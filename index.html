MISI 1 • TELAAH (MINDFUL BRIEFING) Tahap 1 INTROFLEX

Darurat Kalibrasi Sensor Ekologi Danau Limboto

Konteks Masalah (Gorontalo): Danau Limboto merupakan penyangga ekologis utama di Provinsi Gorontalo yang menerima aliran dari Sungai Biyonga, Sungai Alo, dan Sungai Pohu. Untuk mencegah banjir dan memantau pendangkalan (sedimentasi), Tim Riset SMAIT Al Ishlah Gorontalo mengoperasikan sistem Limboto Smart-Gate.

Setiap sensor memodelkan fluktuasi debit air, suhu mesin sterilisasi UMKM Binte Biluhuta, dan struktur pintu air dalam bentuk fungsi polinomial berderajat tinggi $f(x)$. Sistem kontrol hanya membutuhkan nilai sisa pembagian $S(x)$ saat $f(x)$ dibagi oleh modul filter $(x - k)$, $(ax + b)$, atau $(x - a)(x - b)$ sebagai kode kalibrasi (*checksum*).

Kendala Kritis: Chip mikrokontroler pada 30 pelampung sensor memiliki memori sangat terbatas sehingga tidak sanggup melakukan pembagian bersusun panjang setiap detik. Sebagai Tim Insinyur Muda, Anda harus menemukan metode matematis agar sisa pembagian dapat dihitung secara instan!

MISI 2 • EKSPLORASI (PENEMUAN TERBIMBING) Tahap 2 INTROFLEX

Laboratorium Eksplorasi: Pembagian Manual vs Substitusi Nilai Fungsi

Mari kita uji 3 sampel polinomial sensor. Bandingkan sisa hasil pembagian cara bersusun/Horner dengan nilai substitusi langsung $f(k)$ pada pembuat nol pembagi. Apakah keduanya selalu menghasilkan angka yang sama?

SAMPEL LABORATORIUM #1 • Pembagi $(x - k)$ Belum Terverifikasi

Polinomial $f(x) = x^2 - 5x + 8$ dibagi oleh $(x - 3)$. Pembuat nol pembagi: $x - 3 = 0 \Rightarrow x = 3$.
Jika dibagi secara manual: $x^2 - 5x + 8 = (x - 3)(x - 2) + 2$, sehingga hasil baginya $H(x) = x - 2$ dan sisanya $S = 2$.

SAMPEL LABORATORIUM #2 • Pembagi $(x + k)$ Belum Terverifikasi

Polinomial $f(x) = 2x^3 + 3x^2 - 4x + 5$ dibagi oleh $(x + 2)$. Pembuat nol pembagi: $x + 2 = 0 \Rightarrow x = -2$.
Dengan skema Horner untuk $x = -2$, diperoleh hasil bagi $H(x) = 2x^2 - x - 2$ dan sisa pembagian $S = 9$.

SAMPEL LABORATORIUM #3 • Pembagi $(ax + b)$ Belum Terverifikasi

Polinomial $f(x) = 2x^2 + 5x - 1$ dibagi oleh $(2x - 1)$.
Jika dibagi bersusun: $2x^2 + 5x - 1 = (2x - 1)(x + 3) + 2$, sehingga sisanya adalah $S = 2$.

💡 Kesimpulan Pola Eksplorasi: Mengapa $S = f(k)$ Selalu Berlaku?

Ingat algoritma pembagian polinomial: $\text{Yang Dibagi} = (\text{Pembagi}) \times (\text{Hasil Bagi}) + \text{Sisa}$, atau dapat ditulis: $$f(x) = (x - k) \cdot H(x) + S$$ Apa yang terjadi pada suku $(x - k) \cdot H(x)$ jika kita menyubstitusikan pembuat nol pembagi yaitu $x = k$?
