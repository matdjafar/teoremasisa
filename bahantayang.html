Kilas Balik Pertemuan Ke-3

Pembagian Bersusun & Skema Horner vs Kebutuhan Sensor Real-Time

"Pada pertemuan lalu, kita membagi polinomial derajat 4 seperti $f(x) = 2x^4 - 3x^3 + x - 5$ dengan cara bersusun dan Horner. Bagaimana jika 30 sensor pelampung di Danau Limboto hanya butuh nilai SISANYA saja setiap detik untuk kode verifikasi—apakah kita tetap wajib mencari hasil bagi $H(x)$-nya?"

Jika kita hanya membutuhkan Sisa ($S$), menghitung seluruh koefisien Hasil Bagi $H(x)$ akan membuang memori dan waktu komputasi. Dengan Teorema Sisa, kita cukup menyubstitusikan pembuat nol pembagi langsung ke $f(x)$!
Pemanasan Prasyarat (Ketuk Kartu untuk Membuka)

Cek Cepat: Menentukan Pembuat Nol Pembagi Linear

PEMBAGI #1
Pembagi: $(x - 3)$
Ketuk untuk lihat pembuat nol ➔
$x - 3 = 0 \implies x = 3$
PEMBAGI #2 (Waspada Tanda!)
Pembagi: $(x + 2)$
Ketuk untuk lihat pembuat nol ➔
$x + 2 = 0 \implies x = -2$
PEMBAGI #3 (Bentuk $ax+b$)
Pembagi: $(2x - 1)$
Ketuk untuk lihat pembuat nol ➔
$2x - 1 = 0 \implies x = \frac{1}{2}$
PEMBAGI #4 (Pecahan Negatif)
Pembagi: $(3x + 1)$
Ketuk untuk lihat pembuat nol ➔
$3x + 1 = 0 \implies x = -\frac{1}{3}$

MISI 2 • EKSPLORASI (CARI TAHU & BUKTIKAN SENDIRI — KERJA KELOMPOK)

Simulator Pembuktian: Pembagian Manual vs Substitusi $f(k)$

PENALARAN DEDUKTIF INTI

Mengapa Kita Tidak Perlu Menghitung $H(x)$?

Ingat identitas dasar pembagian polinomial:

$$f(x) = \underbrace{(x - k)}_{\text{Pembagi}} \cdot \underbrace{H(x)}_{\text{Hasil Bagi}} + \underbrace{S}_{\text{Sisa}}$$

Apa yang terjadi jika kita substitusikan pembuat nol pembagi yaitu $x = k$?

$$f(k) = \underbrace{(k - k)}_{0} \cdot H(k) + S$$ $$f(k) = 0 \cdot H(k) + S \implies \mathbf{S = f(k)}$$

Suku $(k-k)\cdot H(k)$ lenyap menjadi $0$ berapapun bentuk $H(x)$! Inilah rahasia kecepatan komputasi Teorema Sisa.

MISI 3 • RUMUSKAN (SIMPULKAN KONSEPNYA)

Cetak Biru 4 Rumus Teorema Sisa Polinomial

Ketuk masing-masing kartu di papan interaktif setelah peserta didik menyusun kartu Drag & Drop / Tap-to-Place pada Misi 3:

CETAK BIRU #1 • PEMBAGI LINEAR SEDERHANA Ketuk Buka/Tutup

Jika $f(x)$ dibagi oleh $(x - k)$

Pembuat nol: $x - k = 0 \implies x = k$
$$\text{Sisa } (S) = f(k)$$
CETAK BIRU #2 • WASPADA TANDA NEGATIF PECAHAN! Ketuk Buka/Tutup

Jika $f(x)$ dibagi oleh $(ax + b)$ dengan $a \neq 0$

Pembuat nol: $ax + b = 0 \implies x = -\frac{b}{a}$ (Bukan $+\frac{b}{a}$!)
$$\text{Sisa } (S) = f\left(-\frac{b}{a}\right)$$
CETAK BIRU #3 • PEMBAGI KUADRAT (DERAJAT 2) Ketuk Buka/Tutup

Jika $f(x)$ dibagi oleh $(x - a)(x - b)$

Karena pembagi berderajat $2$, maka derajat sisa maksimal berderajat $2 - 1 = 1$ (berbentuk linear):

$$S(x) = px + q \quad \text{dengan} \quad \begin{cases} f(a) = p\cdot a + q \\ f(b) = p\cdot b + q \end{cases}$$
CETAK BIRU #4 • JEMBATAN KE TEOREMA FAKTOR Ketuk Buka/Tutup

Syarat $(x - k)$ Habis Membagi / Faktor dari $f(x)$

Habis dibagi berarti tidak meninggalkan residu (sisa bernilai nol):
$$S = f(k) = 0$$

BEDAH KASUS STEM #1 • KOTAK #21 [S-T-M]

Sensor Sedimentasi Danau Limboto (Pembagi Kuadrat)

Polinomial laju endapan lumpur $f(x)$ diuji modul $(x - 2)$ mencatat residu $9$, dan diuji modul $(x + 3)$ mencatat residu $-6$. Jika dibagi filter kuadrat $(x^2 + x - 6)$, tentukan ekspresi sisa $S(x) = px + q$!

Langkah 1 (Faktorkan Pembagi): $x^2 + x - 6 = (x - 2)(x + 3)$. Misalkan $S(x) = px + q$.
Langkah 2 (Susun Sistem Persamaan): $$f(2) = 9 \implies 2p + q = 9 \quad \text{...(1)}$$ $$f(-3) = -6 \implies -3p + q = -6 \quad \text{...(2)}$$
Langkah 3 (Eliminasi $q$): Kurangkan (1) dan (2): $5p = 15 \implies p = 3$, lalu $2(3) + q = 9 \implies q = 3$.
Jadi, rumus sisa kalibrasinya adalah $S(x) = 3x + 3$.
BEDAH KASUS STEM #2 • KOTAK #22 [T-E-M]

Struktur Pintu Air Sungai Biyonga (Parameter Ganda)

Tegangan lengkung pintu air $f(x) = x^4 + ax^3 - 3x^2 + bx - 4$ harus habis dibagi oleh $(x^2 - x - 2)$ agar bebas getaran harmonik ($S = 0$). Tentukan nilai $(a + b)$!

Langkah 1 (Faktorkan Pembagi): $x^2 - x - 2 = (x - 2)(x + 1)$. Syarat habis dibagi: $f(2) = 0$ dan $f(-1) = 0$.
Langkah 2 (Trik Efisien Substitusi $x = -1$): $$f(-1) = (-1)^4 + a(-1)^3 - 3(-1)^2 + b(-1) - 4 = 0$$ $$1 - a - 3 - b - 4 = 0 \implies -(a + b) - 6 = 0 \implies \mathbf{a + b = -6}$$
💡 Catatan Insinyur: Dengan mengamati struktur yang ditanyakan yaitu $(a+b)$, kita cukup mengevaluasi $f(-1)=0$ tanpa harus mengeliminasi $a$ dan $b$ satu per satu!
